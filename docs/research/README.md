# Research notes (index)

These are the working notes written while building the mod, **in Spanish**, in roughly the
order things happened. Every address and offset is for Crimson Desert build **1.0.0.2976**.
Many notes were later superseded by newer ones (for example the rope series
`arbol-cuerda-*`), so check the date at the top of each note, and treat the code in `src/` as
the final word.

Good starting points: `troc-sintesis.md` (how the game's internal client/server messages
work), `combate-coop.md` (combat), `enemigos-del-anfitrion.md` and
`fase5-suprimir-enemigos-invitado.md` (shared enemies), and the three security reviews in
`seguridad/`.

Glossary: *anfitrión* = host, *invitado* = guest, *copia* = copy (of an enemy or player),
*botín* = loot, *cuerda* = rope, *árbol* = tree, *captura* = packet capture,
*pendiente* = open issue, *pieza* = piece (part of a milestone), *hito* = milestone.
`data/troc_messages_2976.csv` is the table of the game's internal messages for this build.
The `analisis-ia2/` reports are an independent review of the 7 Oct tests.
